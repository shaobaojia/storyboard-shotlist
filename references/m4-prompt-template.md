# 模块4 提示词模板

> Agent 人和代理程序共用此模板。修改一处，两方生效。

> **⚠️ 管线前提（2026-07 实测更新）：** 场景角度由**机位帧**承载——文本控制机位角度已被实测证伪：视频模型的空间理解锚定在场景图自身的角度上，「空间锚」类文字描述掰不动它。机位帧 = 分镜完成后、提示词开始前，用视频模型（快乐小马 1.1 等）从场景设定图摇出的特定角度帧。**同角度的镜头共用一张机位帧。** 文本的职责收窄为：帧基础上的机位微调 + 镜头内运镜 + 表演 + 光效锚定。

## 模板结构

```
人物：{身份锚定——谁是谁、脸部/服装一致性（配合角色设定图防身份漂移）。
      不承载位置信息——位置归各镜头的空间关系行。
      按「人物两步法」（见跨镜合并规则）执行。每人独立一行。
      有上游继承 → `@图片N — {角色速写}`；无上游 → 只写角色名。}

场景：{机位帧清单——按角度逐行声明，每行格式：
      `@图片 — {角度标签}：{帧内容一句话描述}`
      角度标签直接对应分镜表机位列编码，例：
        @图片 — 正打：男人正面，背景宠物店橱窗
        @图片 — 反打：男人所见方向，电玩城门口
        @图片 — 侧拍（格栅前景）：宠物店内透过狗笼格栅
      @ 为占位标记，不编号——拷入生图模型时手动挂对应帧即可。
      镜头行的拍摄方式只写「{角度标签}机位，{微调}，{运镜}」，不再逐镜 @图片——声明区已建立标签↔帧的唯一映射。
      唯一性铁律：同一组内同一角度标签只对应一张帧；若同标签出现两张帧（如两个不同正打帧），退回逐镜「基于@图片」显式绑定。
      无机位帧时退回文字描述：一句话概括环境元素，不展开。}

道具：{按人物两步法同样处理——扫描本组镜头的动作调度列+空间关系列提取关键道具（币、手机、手环等）。
      有设定图 → `@图片N — {道具速写}`；无设定图 → 一句话一致性描述。
      本组无关键道具时省略此行。}

镜头一：[镜NN]
空间关系：t0 静态布局——起幅瞬间谁在画面哪里。以镜头（机位帧）视角为基准，画面系描述，「左/右」允许。原料：v2 空间关系列直接翻译。帧位覆盖铁律：人物/道具的位置以本行为准，覆盖机位帧内的位置——机位帧只提供机位角度，不代表本镜起幅时人物在哪。只写静态布局，不写动态事件——动态归动作表演和画面动态。
动作表演：谁做了什么。原料：v2 动作调度列 + 台词列，严格剔除两类非动作内容：①摄影机描述（入画、出画、镜头如何运动）；②灯光与画面效果描述（屏幕冷光、逆光、暖光笼罩等）——效果归主光方位和画面动态管。台词原文紧随动作后，用「」包裹。主语铁律：每个镜头的动作表演必须以明确的主语开头——「男人……」「气球……」「拇指……」。多角色镜头中必须写明每个动作的执行者，禁止用省略主语的方式罗列动作。只写角色的肌肉动作、视线、呼吸、微表情、台词。对象不是角色时写物体行为。方向词铁律：「左右」依赖镜头视角→禁止；「前后」基于角色自身基准→允许。没有镜头就没有左右。画面外禁令：禁止引用本镜头画面内不可见的元素，否则视频模型会硬塞入画。
拍摄方式：帧绑定 + 机位微调 + 运镜。开头绑定机位帧：「基于@图片，……」。机位微调 = 基于帧角度的细微变化——略高/略低、微俯/微仰、左斜/右斜。文本只做微调，不做角度大跳：「相机在X右侧」级别的角度改变由机位帧承载，文字掰不动。运镜 = 镜头内的推拉摇跟（叙事动机铁律：运镜不是纯粹的机械运动——交代摄影机为什么动、透过谁的视角看、运镜的目标是什么。技术术语（OTS、POV、dolly 等）不禁止，但必须嵌入叙事上下文——不写「OTS 绕到正面」，写「过脸OTS绕到正面近景」。裸术语没有叙事锚 → 不合格）。主体铁律：机位描述必须绑定主体，多角色镜头中禁止只写「正面拍摄」不写拍谁。原料：机位帧引用 + v2 运镜列 + 摄影机列 + 机位列。
画面动态：
{起幅/落幅结构的镜头拆为独立行，每行不以「画面动态：」开头再拼一句：
  起幅：{起幅构图}
  {运镜动作，如「上摇：裤腿→胸口→下巴依次入画」}
  落幅：{落幅后构图}
 景别不变的跟拍/手持无需拆分，内容直接写在「画面动态：」下一行。}
主光方位：防塑料补光——实测：提示词完全不提灯光时，模型会给角色加不自然的塑料感补光。任务：把角色身上的光锚定到帧内实际存在的 practical 光源上。原料：机位帧内可见光源 + 场景 practicals，不发明光源。亮度关系模板见「主光方位」节。时间性光事件（霓虹轮转、屏幕亮起等帧给不了的）也写在本行。

镜头二：
...
```

## 五行分工

| 行 | 职责 | 原料来源 | Agent 自由度 |
|:---|:---|:---|:---|
| 空间关系 | t0 起幅布局（静态），覆盖帧内人物位置 | v2 空间关系列 | 只翻译，不发明 |
| 动作表演 | 角色做了什么 | v2 动作调度列 + 台词列（剔除摄影机+灯光效果描述） | 只翻译，不发明 |
| 拍摄方式 | 帧绑定 + 机位微调 + 运镜 | 机位帧引用 + v2 运镜/摄影机/机位列 | 编码→自然语言，微调幅度不超出「细微变化」 |
| 画面动态 | 布局的时序变化（无变化则整行省略） | 动作表演 + 拍摄方式 + 空间关系推演 | 唯一允许判断的行——时间线、节奏、先后顺序 |
| 主光方位 | 角色光锚定（防塑料补光） | 机位帧内可见光源 + 场景 practicals | 从帧和场景推演，不发明光源 |

## 五行数据源

| 行 | v2 数据源 | 规则 |
|:---|:---|:---|
| 空间关系 | 空间关系列 | `[后][中][前][左][右]` 编码直接翻译为画面系自然语言。t0 静态布局，不写动态事件。人物/道具位置以本行为准，覆盖机位帧内位置。 |
| 动作表演 | 动作调度列 + 台词列 | 强制合并（两列对照，不可跳过）：①并排列出动作调度列原文和台词列原文。②确定每句台词在动作序列中的插入位置。③合并输出——动作描述中自然织入台词，用「」包裹。禁止跳过台词列，禁止只写动作不提台词。剔除两类非动作内容：摄影机描述 + 灯光/画面效果描述。方向词铁律：左右禁（镜头视角），前后允（角色基准）。画面外禁令：禁引本镜不见的元素。 |
| 拍摄方式 | 机位帧引用 + 运镜列 + 摄影机列 + 机位列 | 开头「基于@图片N」绑定机位帧。机位微调只写细微变化（略高/略低、微俯/微仰、左斜/右斜）。运镜编码转自然语言，技术术语须嵌入叙事上下文——不写裸「OTS」，写「过脸OTS绕到正面近景」。🟢三只写物理机位（「侧面拍摄{角色}」），不写「第三人称」「客观视角」——每段提示词独立，视频模型无上下文。🔵环=空间环境交代，景别以摄影机列为准。 |
| 画面动态 | 动作表演 + 拍摄方式 + 空间关系 | 只写布局的时序变化。入画出画必须标注方向（「从画右入画」「从画左出画」）。起幅/落幅（景别变化的运镜镜头）拆三段：「起幅——」/「运镜动作+焦点转移」/「落幅——」；景别不变的跟拍/手持无需拆分。固定机位+布局无变化→整行省略。禁止重复动作表演或空间关系内容。 |
| 主光方位 | 机位帧内可见光源 + 场景 practicals | 把角色的光锚定到帧内实际存在的 practical。不发明光源。时间性光事件（霓虹轮转、屏幕亮起）写在本行。 |

## 机位编码 → 自然语言

> 机位帧管线下，机位角度的主要控制权在机位帧生产阶段——同机位的镜头共用一帧。拍摄方式行的机位描述 = 帧绑定 + 微调，以下写法用于绑定语句：

| v2 编码 | 提示词写法 | 说明 |
|:---|:---|:---|
| 🔴正 | 基于@图片，正面拍摄{角色} | 需写明拍摄对象 |
| 🟡反 | 基于@图片，{角色}POV | 需写明谁的视角 |
| 🟢三 | 基于@图片，侧面拍摄{角色} | 直接写物理机位，不写「第三人称」「客观视角」——每段提示词独立，视频模型无上下文 |
| 🔵环 | 基于@图片，空间环境交代 | 景别以摄影机列为准，不固定为全景 |
| 🟣插 | 插入/闪回 | 闪回空间通常无机位帧，退回文字描述质感建立 |

## 主光方位

每个镜头独立一行。**任务：防塑料补光。** 实测结论：提示词完全不提灯光时，角色会出现塑料感的不自然补光。本行的作用是把角色身上的光锚定到帧内实际存在的 practical 光源上，堵住模型自作主张补光的口子——不是描述环境光（那已烘在机位帧里），是声明角色与光的亮度关系。

数据源：机位帧内可见光源 + 场景 practicals。风格块已定纪律（仅 practicals、阴影侧拍），主光方位定执行——哪个灯、从哪打、在角色身上产生什么效果。

### 通用模板：走廊/过道强背光

适用于商场过道、走廊、中庭等有一侧主光源穿透的纵深空间。效果：人物暗部自然沉入阴影，仅保留柔和的轮廓光，不做硬剪影。

```
所有人物的亮度呈剪影状，光线从画面{左/右}的{具体光源}打来，在人物身上产生柔和的轮廓光。
```

- `{左/右}` 与机位帧内光源方位一致
- `{具体光源}` 必须是场景内实际存在的 practical（中庭天光、商场顶灯、电玩城门牌霓虹等）
- 面部特写、近景同样适用——「剪影状」是亮度描述不是形态描述，暗部自然压低但不丢失面部微表情

## 命名约定

- 提示词内「镜头一/二/…」是合并组内的局部序号，不绑定 v2 内部镜号
- 所有讨论以 v2 分镜表的绝对镜号为准（镜 02、镜 03）
- 提示词中用 `[镜NN]` 格式标注映射关系
- 机位帧引用 → `@图片 — {机位帧描述}`；无机位帧 → `场景：{地点，时间。2-3 个关键环境元素。}`
- 人物/道具引用 → `@图片 — {角色速写}`；无参考图 → 写角色名或一句一致性描述
- @ 为占位标记，不编号——拷入生图模型时手动挂对应参考图

## 跨镜合并规则

- 共享声明（人物 / 场景（机位帧清单）/ 道具 / 风格块）全文从上游提示词组继承，不重新生成
- 上游 = 同一场次内，镜号小于当前组、且有完整正文（非 ↑ 继承标记）的最近一个提示词组
- **断链回溯：** 人物/道具两步法查上游时，如果最近的上游组不含该角色/道具（如纯物件镜组），跳过该组继续向上回溯，直到找到最近的完整描述为止
- 机位帧清单不继承——每组按本组镜头实际用到的帧重新列出
- 本场第一组提示词（通常是镜 02）无上游可继承，由 Agent 手动生成共享声明

### 人物两步法（每次生成新组时执行）

跨场角色集不固定——用户手动编辑可能引入新角色。继承上游之前必须先扫描当前组。道具行按同样的两步法处理。

**第一步：扫描当前组。** 遍历本组所有镜头的 `动作调度` 列和 `空间关系` 列，提取全部角色名（道具行：提取关键道具名）。不区分主次——只要出现就收集。

**第二步：逐角色查上游。**
- 上游有该角色 → 继承上游的完整描述（`@图片N — {角色速写}`，含年龄、体型、服装等）
- 上游无该角色 → 断链回溯：跳过不含该角色的组继续向上查；全场都无 → 只写角色名，不加 `@图片` 标记，不编造描述

示例：上游人物声明为 `@图片1 — 男人，38-42岁……@图片2 — 小孩，5-6岁……`，当前组扫出男人、小孩、奶奶。输出人物行（每人独立一行）：
```
人物：
@图片1 — 男人，38-42岁……
@图片2 — 小孩，5-6岁……
奶奶。
```

## 画面外禁令（全局）

提示词全文——场景、空间关系、动作表演、画面动态——禁止描述当前画面内不可见的任何元素。AI 视频模型会把提示词中提到的每个名词塞进画面。画外对象（如「摄影机背后有电玩城」）不要写、不要暗示、不要用否定句提（「没有 XX」也会触发）。只写画面内实际存在、观众能看到的东西。

## 生成后自检（写入飞书前）

> 生成完提示词、PUT 写飞书之前，逐项检查以下四项。全部 ✅ 才能写。本清单与 SKILL.md 模块4 步骤5 同步——两处修改一处，另一方必须同步。

| # | 检查项 | 查什么 | 常见翻车 |
|:---|:---|:---|:---|
| 1 | 台词合并 | 每个镜头的动作表演是否对照了飞书**台词列**？台词列非空时，必须织入台词原文（`「」`包裹）。禁止只用动作调度列跳过台词列 | 用户改动作调度时可能删了台词事件，但台词列还留着旧值——必须逐镜对照两列 |
| 2 | 画面动态省略 | 固定机位 + 布局无起幅落幅变化 → 画面动态整行删除。模板规定「无变化整行省略」 | 容易顺手给固定镜头写「画面内唯一动态」之类的兜底描述——那是动作表演，不是布局变化 |
| 3 | 🟣插 质感建立 | 🟣插 的拍摄方式行：闪回空间无机位帧，必须退回文字描述质感建立（暖调过曝、边缘柔化等）。禁止写标准机位描述（「正面拍摄。固定机位。中景。」） | 闪回镜头容易按普通镜头处理，写出标准相机参数而非质感 |
| 4 | 同义重复 | 同一句子是否在提示词中出现两次？生成时容易把 v2 动作调度原文里的描述在提示词末尾再写一遍 | 镜33 曾出现「目光从画外上方缓缓移下」重复两次 |

## 风格块（全局约定，所有提示词末尾统一拼接）

```
风格块：
整体风格：8K IMAX。超写实——禁3D渲染，禁游戏引擎，禁游戏CG过场质感。
摄影风格：Emmanuel Lubezki × Roger Deakins。
灯光风格：⚠️严格仅使用场景内实际存在的光源（practicals）。禁止一切电影补光——禁正面光、禁侧面补光、禁顶光、禁底光、禁反光板、禁柔光箱、禁LED灯带、禁霓虹、禁任何画面外光源。摄影机始终在人物的阴影侧（shadow side）拍摄。全程大气薄雾haze——禁止上帝光（god rays）。
色彩风格：60:30:10——主色/辅色/点缀色。
镜头风格：物理电影镜头。180°快门运动模糊。
皮肤风格：毛孔级写实——汗毛、不对称痣、毛细血管潮红、毛孔阴影匹配现场光源。
表演风格：好莱坞级——反应前微停顿、精准视线、湿润活眼带眼神光、可见呼吸和胸腔起伏。
物理风格：重力惯性真实——质量有真实重量、正确接触阴影。禁漂浮道具。
构图风格：三分法+黄金比例。每人从第一帧开始运动。
连续性：角色、道具、环境每个镜头完全一致。禁身份漂移。
技术：标准电影帧率24帧每秒。8K细节。禁抖动（除手持呼吸感）。
音频：仅环境音效。禁音乐。禁字幕。
```
