# 前端一键生成提示词 · 可行性验证

> 2026-07-13 用 DeepSeek API 直调验证通过。

## 链路

```
前端多选镜头 → POST 镜号列表 + 飞书数据 → 代理拼装 prompt
  → DeepSeek API（模块4 模板为 system prompt）
  → 返回提示词文本 → PUT 写回飞书 → 前端 🔄
```

## 测试结果

- 输入：镜 13-15 数据（3 镜头，beat 3 戏点） + 上游共享声明 + 模块4 完整模板
- 模型：`deepseek-chat`，temperature=0.3，max_tokens=3000
- 成本：1068 prompt + 557 completion = 1625 tokens（极低）
- 质量：结构准确（四行/镜头、三段画面呈现、机位绑定主体），共享声明完整继承

## 发现

1. system prompt 必须包含**完整模块4模板**（精简版输出格式混乱）
2. 共享声明（人物/场景/空间锚）从上游提示词组继承，不改动
3. 风格块需在 prompt 末尾显式要求拼接（否则漏掉）
4. 动作调度列中的「镜头」「入画」等摄影机描述需剔除后归入动作表演
