# 画面呈现两步校验法

## 前提

画面呈现的三种原料：动作表演、拍摄方式、空间关系。其中空间关系是空间事实的唯一基准。

## 第一步：推演草稿

用动作表演和拍摄方式推演出画面描述草稿。按时间线融合——

- 谁在干什么（来自动作表演）
- 摄影机怎么动（来自拍摄方式）
- 景别何时变、谁先谁后

暂时不引入空间关系的方位信息。这一步产出一段自然语言草稿。

## 第二步：空间收敛

将草稿与空间关系逐位比对：

| 空间关系元素 | 比对项 |
|-------------|--------|
| `[前左]` 取币机 | 草稿中取币机是否在前景左侧 |
| `⤳ 横移 →` | 草稿中镜头运动方向和路径是否一致 |
| `[右⅓]` 👤男人(由远及近) | 草稿中男人位置和深度变化是否一致 |

### 比对结果处理

**通过 →** 草稿自洽，直接输出为画面呈现。

**冲突 →** 在画面呈现段中显式标注：

```
⚠ 空间冲突：草稿中X，但空间关系指示Y。需人工定夺。
```

Agent 不得自行"修正"冲突——空间关系是导演设定的空间事实，Agent 无权改写。

## 示例

**镜头一的草稿：**
> 取币机币筐近景，币堆成小山。镜头横向右移，取币机退出画面。男人从远处沿过道走来，由远及近。

**空间关系：** `[前左] 取币机 ⤳ 横移 → [右⅓] 👤男人(由远及近)`

逐一比对：
- `[前左]取币机` ↔ `取币机币筐近景` ✅ 前=近景, 左=取币机在左
- `⤳ 横移 →` ↔ `镜头横向右移` ✅
- `[右⅓]👤男人(由远及近)` ↔ `男人由远及近` ✅ （右⅓隐含未显写，可接受）

→ 通过，输出。
