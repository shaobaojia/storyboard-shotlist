# 模块4 提示词模板

> Agent 人和代理程序共用此模板。修改一处，两方生效。

## 模板结构

```
人物：{按「人物两步法」（见跨镜合并规则）执行。每人独立一行。}
      {有上游继承 → `@图片N — {角色速写}`；无上游 → 只写角色名。}
      {本场第一组提示词（无上游）时，扫描当前组所有镜头的动作调度列和空间关系列，逐一列出：有参考图写「@图片N — {角色速写}」，无参考图写「{角色名}，{年龄}，{体型}，{特征}，{服装}」。
       每人独立一行。}

场景：{有参考图时：直接声明引用，如"@图片3 控制场景"}
      {无参考图时：一句话概括环境元素，不展开。}

空间锚：{基于物理锚点的空间关系——谁在哪、挨着什么、朝哪走、与周围物件的距离和相对位置。
         禁止写左右/前后/上下等画面方向词——那是机位列的活。}

镜头一：[镜NN]
动作表演（原「演」）：谁做了什么。原料：v2 动作调度列 + 台词列，严格剔除两类非动作内容：①摄影机描述（入画、出画、镜头如何运动）；②灯光与画面效果描述（屏幕冷光、逆光、暖光笼罩等）——效果归主光方位和画面呈现管。台词原文紧随动作后，用「」包裹。主语铁律：每个镜头的动作表演必须以明确的主语开头——「男人……」「气球……」「拇指……」。多角色镜头中必须写明每个动作的执行者，禁止用省略主语的方式罗列动作。只写角色的肌肉动作、视线、呼吸、微表情、台词。对象不是角色时写物体行为。方向词铁律：「左右」依赖镜头视角→禁止；「前后」基于角色自身基准→允许。没有镜头就没有左右。画面外禁令：禁止引用本镜头画面内不可见的元素，否则视频模型会硬塞入画。
拍摄方式（原「拍」）：摄影机怎么拍、拍谁、为什么这样拍。原料：仅 v2 运镜列 + 摄影机列 + 机位列，三列以外的一切（导演备注、灯光描述、氛围词）都不属于拍摄方式。自然语言，不写内部编码。叙事动机铁律：运镜不是纯粹的机械运动——交代摄影机为什么动、透过谁的视角看、运镜的目标是什么。技术术语（OTS、POV、dolly 等）不禁止，但必须嵌入叙事上下文——不写「OTS 绕到正面」，写「过脸OTS绕到正面近景」：包含了主体（过谁的脸）、技术锚点（OTS）、运动（绕）和落幅目标（正面近景）。裸术语没有叙事锚 → 不合格。主体铁律：机位描述必须绑定主体——🔴正 →「正面拍摄男人」；🟡反 →「男人 POV」或「透过小孩的眼睛看」；🟢三 →「侧面客观视角，相机在男人右侧」；🔵环 → 空间环境交代（景别以摄影机列为准，不固定为全景）；🟣插 → 插入/闪回。多角色镜头中禁止只写「正面拍摄」不写拍谁。
画面呈现（原「呈」）：最终画面——观众看到什么（构图+表演，不含打光效果）。两步法：①用动作表演和拍摄方式推演画面草稿。②将草稿与空间关系逐位比对——空间关系是空间事实的唯一基准，用它收敛草稿。比对通过→输出；比对发现方位冲突→显式标注「⚠ 空间冲突：xxx，需人工定夺」。构图要求：将空间关系的纵深编码翻译为构图语言（前景/中景/远景、左/中/右、近/远），先定构图骨架，再叠动作和运镜。与主光方位的边界铁律：画面呈现只管构图和表演——前景/中景/远景、人物的位置和动作、运镜带来的空间变化。光源方向、亮度、轮廓光等打光效果全部归主光方位，画面呈现不重复。方向词规则：画面呈现在相机视角下描述，「左/右」是基于画面的视觉事实→允许。与动作表演的方向词禁令不矛盾。

镜头二：
...
```

## 三层分工

| 行 | 职责 | 原料来源 | Agent 自由度 |
|:---|:---|:---|:---|
| 动作表演 | 角色做了什么 | v2 动作调度列（剔除摄影机+灯光效果描述） | 只翻译，不发明 |
| 拍摄方式 | 摄影机怎么拍、为什么这样拍 | v2 运镜 + 摄影机 + 机位列 | 编码→自然语言，技术术语可保留但须嵌入叙事上下文，不发明 |
| 画面呈现 | 观众看到什么（构图+表演） | 动作表演 + 拍摄方式 + 空间关系融合 | 唯一允许判断的行——时间线、节奏、先后顺序。禁写打光效果 |

## 机位编码 → 自然语言

| v2 编码 | 提示词写法 | 说明 |
|:---|:---|:---|
| 🔴正 | 正面拍摄{角色} | 需写明拍摄对象 |
| 🟡反 | {角色}POV | 需写明谁的视角 |
| 🟢三 | 侧面客观视角，相机在{角色}{方位} | 需写明相机相对谁的位置 |
| 🔵环 | 空间环境交代 | 景别以摄影机列为准，不固定为全景 |
| 🟣插 | 插入/闪回 | |

## 三层数据源

| 行 | v2 数据源 | 规则 |
|:---|:---|:---|
| 动作表演 | 动作调度列 + 台词列 | 强制合并（两列对照，不可跳过）：①并排列出动作调度列原文和台词列原文。②确定每句台词在动作序列中的插入位置。③合并输出——动作描述中自然织入台词，用「」包裹。禁止跳过台词列，禁止只写动作不提台词。剔除两类非动作内容：摄影机描述 + 灯光/画面效果描述。方向词铁律：左右禁（镜头视角），前后允（角色基准）。画面外禁令：禁引本镜不见的元素。 |
| 拍摄方式 | 运镜列 + 摄影机列 + 机位列 | 编码转自然语言。技术术语（OTS、POV、dolly 等）不禁止但须嵌入叙事上下文——不写裸「OTS」，写「过脸OTS绕到正面近景」。🟢三侧位从动作调度反推。🔵环=空间环境交代，景别以摄影机列为准。 |
| 画面呈现 | 动作表演 + 拍摄方式 + 空间关系 | 两步法：①推演草稿 ②空间关系收敛。构图：前景/中景/远景 + 左/中/右 + 近/远。方向词：画面呈现有相机视角→左右允许。起幅/落幅（运镜镜头）：景别变化的运镜镜头，画面呈现拆为三段——「起幅——」描述起幅构图、「运镜动作+焦点转移」在中间独立一行、「落幅——」描述落幅后构图。景别不变的跟拍/手持无需拆分。边界铁律：画面呈现不写打光效果——光源方向、亮度、轮廓光全部归主光方位。 |

## 主光方位

每个镜头独立一行，描述主光源来源和方向。数据源：场景描述（光源类型）+ 空间锚（光源位置）+ 空间关系（光线方向推演）。风格块已定纪律（仅 practicals、阴影侧拍），主光方位定执行——哪个灯、从哪打、什么效果。

### 通用模板：走廊/过道强背光

适用于商场过道、走廊、中庭等有一侧主光源穿透的纵深空间。效果：人物暗部自然沉入阴影，仅保留柔和的轮廓光，不做硬剪影。

```
所有人物的亮度呈剪影状，光线从画面{左/右}的{具体光源}打来，在人物身上产生柔和的轮廓光。
```

- `{左/右}` 从画面呈现行取——跟空间关系列的方位一致
- `{具体光源}` 必须是场景内实际存在的 practical（中庭天光、商场顶灯、电玩城门牌霓虹等）
- 面部特写、近景同样适用——「剪影状」是亮度描述不是形态描述，暗部自然压低但不丢失面部微表情

## 命名约定

- 提示词内「镜头一/二/…」是合并组内的局部序号，不绑定 v2 内部镜号
- 所有讨论以 v2 分镜表的绝对镜号为准（镜 02、镜 03）
- 提示词中用 `[镜NN]` 格式标注映射关系
- 有场景参考图 → `场景：@图片3 控制场景`；无参考图 → `场景：{地点，时间。2-3 个关键环境元素。}`

## 空间锚铁律

- 空间锚 = 角色的物理位置关系，不是画面构图
- 写「挨着护栏」「从取币机旁出发」——场景内的物理事实
- 不写「画面左侧」「画面右侧」「前景」「背景」——摄影机的选择，归拍摄方式行

## 跨镜合并规则

- 共享声明（人物/场景/空间锚/风格块）全文从上游提示词组继承，不重新生成
- 上游 = 同一场次内，镜号小于当前组、且有完整正文（非 ↑ 继承标记）的最近一个提示词组
- 本场第一组提示词（通常是镜 02）无上游可继承，由 Agent 手动生成共享声明

### 人物两步法（每次生成新组时执行）

跨场角色集不固定——用户手动编辑可能引入新角色。继承上游之前必须先扫描当前组。

**第一步：扫描当前组。** 遍历本组所有镜头的 `动作调度` 列和 `空间关系` 列，提取全部角色名。不区分主次——只要出现就收集。

**第二步：逐角色查上游。**
- 上游有该角色 → 继承上游的完整描述（`@图片N — {角色速写}`，含年龄、体型、服装等）
- 上游无该角色 → 只写角色名，不加 `@图片` 标记，不编造描述

示例：上游人物声明为 `@图片1 — 男人，38-42岁……@图片2 — 小孩，5-6岁……`，当前组扫出男人、小孩、奶奶。输出人物行（每人独立一行）：
```
人物：
@图片1 — 男人，38-42岁……
@图片2 — 小孩，5-6岁……
奶奶。
```

## 画面外禁令（全局）

提示词全文——场景、空间锚、动作表演、画面呈现——禁止描述当前画面内不可见的任何元素。AI 视频模型会把提示词中提到的每个名词塞进画面。画外对象（如「摄影机背后有电玩城」）不要写、不要暗示、不要用否定句提（「没有 XX」也会触发）。只写画面内实际存在、观众能看到的东西。

## 风格块（全局约定，所有提示词末尾统一拼接）

```
整体风格：8K IMAX。超写实——禁3D渲染，禁游戏引擎，禁游戏CG过场质感。
摄影风格：Emmanuel Lubezki × Roger Deakins。
灯光风格：⚠️严格仅使用场景内实际存在的光源（practicals）。禁止一切电影补光——禁正面光、禁侧面补光、禁顶光、禁底光、禁反光板、禁柔光箱、禁LED灯带、禁霓虹、禁任何画面外光源。摄影机始终在人物的阴影侧（shadow side）拍摄。全程大气薄雾haze——禁止上帝光（god rays）。
色彩风格：60:30:10——主色/辅色/点缀色。
镜头风格：物理电影镜头。180°快门运动模糊。
皮肤风格：毛孔级写实——汗毛、不对称痣、毛细血管潮红、毛孔阴影匹配现场光源。
表演风格：好莱坞级——反应前微停顿、精准视线、湿润活眼带眼神光、可见呼吸和胸腔起伏。
物理风格：重力惯性真实——质量有真实重量、正确接触阴影。禁漂浮道具。
构图风格：三分法+黄金比例。每人从第一帧开始运动。
连续性：角色、道具、环境每个镜头完全一致。禁身份漂移。
技术：标准电影帧率24帧每秒。8K细节。禁抖动（除手持呼吸感）。
音频：仅环境音效。禁音乐。禁字幕。
```
